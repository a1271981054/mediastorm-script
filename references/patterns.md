## 一、 核心数据铁律（100期 · 409,956汉字 · 45,720句）

- **气口字数**：全站均值 **9.18 字**，中位数 **9 字**，P90 **15 字**（棚拍独白 9.6–10.1 字，互动/旅行 8.1–8.3 字）。**单句绝不超 20 字不换气。**
- **去爹味铁律**：`我觉得`(596次) vs `我认为`(49次) = **12:1**；称呼只用 **`你`** 或 **`各位`**(133次)，不用 `家人们`；告别词为 **`那么我们，下次再见`**(58次)。
- **自我介绍规则**：95% 的评测/科普/纪实/旅行**第 0 秒直入钩子**；仅在**年度正式汇报、危机公关回应、代际身份切入**时用 `好，各位，我是XX`。
- **逻辑润滑词主力**：`就是`(4.95/千字)、句首 `那`(4.42，评测/AI/科普高达 **6.0+**)、`所以`(3.42，复盘高达 **7.34**)、`但是`(2.61，评测高达 **4.38**)、`真的`(2.01)、`其实`(1.64)、`你看`(1.11)、`有点`(0.74)、`反正`(评测专属 **1.05**)。
- **纯语气助词控温红线**：
  - `呢` 仅用于切维度设问；`吧/对吧/是不是` 仅用于邀约或对比确认；`诶` 仅用于意外解法；`呃` 仅用于冷幽默打脸停顿。
  - 棚拍硬件/AI/复盘**严控 `啊`**(0.00–0.21)且**禁用 `哇`**(0.00–0.02)；`哇/哦` 只留给户外旅行与实物开箱第一眼。
  - **30 秒短视频纯语气助词上限：全篇 ≤ 1–2 个！**
- **绝对零容忍污染词**（41万字实测均为 0 次）：`赋能`、`抓手`、`综上所述`、`封神`、`炸裂`、`保姆级`、`闭眼冲`、`别再xxx了`；同时避免高频堆砌极罕见脑补词（`实话实说` 仅 2 次、`老实说` 仅 3 次、`说白了` 仅 7 次）。

## 三、 四句万能救命句型（写卡壳时直接调用）

1. **立客观开场**：`它有独特的地方吗？那是有的。它有爽的地方吗？也有。但是有的地方，我们测下来差的真的很远。`
2. **破专业门槛**：`[参数/术语]。那是什么概念？简单来说，就相当于你平时……`
3. **丝滑切下段**：`那这时候你肯定会问了：既然它这么 [优点]，那 [最担心的痛点] 怎么办？`
4. **防杠摊牌边界**：`你要说完全没有 [缺点]，那不可能。但是对于大多数日常场景来说……至少我是这个感觉，你可以作为参考。`
